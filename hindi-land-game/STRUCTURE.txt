🔌 API ENDPOINTS (25+)
═════════════════════════════════════════════════════════════════════════════

Authentication:
  POST   /api/auth/token/                 # Get JWT token
  POST   /api/auth/token/refresh/         # Refresh token

Players:
  GET    /api/players/me/                 # Current player profile
  POST   /api/players/create_profile/     # Create new player
  GET    /api/players/{id}/stats/         # Player statistics
  GET    /api/players/{id}/matches_history/

Matches:
  POST   /api/matches/create_match/       # Create new match
  GET    /api/matches/{id}/               # Get match details
  POST   /api/matches/{id}/join/          # Join active match
  POST   /api/matches/{id}/start/         # Start the match
  POST   /api/matches/{id}/end/           # End match & record results
  GET    /api/matches/{id}/leaderboard/   # Match leaderboard

Leaderboard:
  GET    /api/leaderboard/                # Global leaderboard
  GET    /api/leaderboard/by_kills/       # Top by kills
  GET    /api/leaderboard/by_wins/        # Top by wins
  GET    /api/leaderboard/by_wins_rate/   # Top by win rate

Health Check:
  GET    /api/health/                     # API status

🚀 QUICK START (3 STEPS)
═════════════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES
   Backend: python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt
   Frontend: cd frontend && npm install

2. SETUP DATABASE
   cd backend && python manage.py migrate && python manage.py createsuperuser

3. RUN LOCALLY
   Terminal 1: cd backend && python manage.py runserver
   Terminal 2: cd frontend && npm run dev
   
   Access game at: http://localhost:8080

💾 DATABASE MODELS
═════════════════════════════════════════════════════════════════════════════

Player:
  - user (FK: Django User)
  - character_type (farmer, student, worker, vendor, teacher)
  - level, experience, total_kills, total_deaths
  - win_count, highest_kill_streak, total_damage_dealt
  - created_at, updated_at

Match:
  - game_mode (solo, duo, squad)
  - status (waiting, active, ended)
  - current_players, max_players, duration
  - started_at, ended_at, winner
  - created_at, updated_at

MatchPlayer:
  - match (FK), player (FK)
  - kills, deaths, damage_dealt, damage_taken
  - placed_at (1st, 2nd, etc.), elimination_time
  - joined_at, left_at

PlayerStats:
  - player (OneToOne FK)
  - matches_played_today, kills_today
  - total_playtime, last_match_date
